# Chinook SQL & Pandas Business Analysis

## Overview
This project uses the Chinook SQLite database to perform business analysis using SQL and Python (Pandas). The goal is to answer business questions using both approaches and validate that the results match.

## Tools & Technologies
- Python
- SQLite
- SQL
- Pandas
- Git & GitHub

## Project Objectives
- Connect to a SQLite database using Python.
- Load database tables into Pandas DataFrames.
- Analyze business data using SQL and Pandas.
- Compare and validate results from both approaches.
- Extract meaningful business insights.

## Business Questions
1. Top 10 customers by total spending
2. Revenue by country
3. Monthly sales revenue trend
4. Top-selling tracks
5. Revenue by artist
6. Revenue by genre
7. Sales by employee
8. Average invoice value
9. Repeat customers and invoice count
10. Highest-revenue month

## Validation
SQL and Pandas results are compared to ensure both methods produce consistent outputs.

## Project Status
- Database connection and data loading: Completed
- Q1 – Top customers by spending: Completed and validated
- Q2–Q10: In progress

Chinook sample database.

## Purpose
This project is created for hands-on practice in SQL, Python, Pandas, data analysis, and GitHub version control.
